## 원본 샘플이 저장소에 포함되지 않은 이유

악성으로 의심되는 실행 파일(및 그와 유사한 형태의 실행 파일)을 원격 공개
저장소에 그대로 업로드하면 GitHub의 악성코드/시크릿 스캐닝에 의해 저장소가
차단되거나, 이 저장소를 클론하는 사람의 백신 소프트웨어가 자동으로 격리·삭제할
위험이 있다. 따라서 실행 파일 원본은 버전 관리에서 제외(`.gitignore`)하고,
재현성을 위해 SHA-256 해시값만 `SHA256SUMS.txt` 에 기록한다.

분석을 재현하려면 강사에게서 받은 원본 샘플을 이 디렉터리(`samples/`)에
그대로 복사한 뒤, 저장소 루트에서 다음을 실행한다.

```bash
pip install -r requirements.txt
python extract_features.py samples features.csv
```

샘플은 반드시 격리된 환경(예: 네트워크가 차단된 가상머신)에서만 다루며,
어떤 경우에도 실행하지 않는다. 이 저장소의 스크립트는 파일을 바이트 단위로
읽거나 `pefile` 로 파싱만 할 뿐 샘플을 실행하지 않는다.
